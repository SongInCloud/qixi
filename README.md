# 《七月初七》

今夜有星河，亦有一笺寄你。

七夕数字礼物网站，技术栈：Vue 3 + Vite + TypeScript + Sass + GSAP。

## 开发命令

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器（默认 http://localhost:5173）
npm run type-check # 类型检查
npm run build      # 生产构建
```

## 目录结构

```
src/
├── components/   # 可复用组件（StarField 等）
├── sections/     # 五个章节
├── mock/         # 私人内容数据（memories / daughter / letter）
├── styles/       # 设计令牌与全局样式
├── types/        # 类型定义
└── utils/        # 动画工具
```

详细需求见 `docs/七月初七-产品需求文档-PRD.md`。
