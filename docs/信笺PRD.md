# 《七月初七》——七夕数字礼物网站产品需求文档

> 文档版本：v1.0
> 项目类型：个人七夕数字礼物
> 开发方式：AI 辅助开发（GPT + Codex）
> 预计开发时间：12 小时
> 技术栈：Vue 3 + Vite + TypeScript
> 数据方式：本地 Mock 数据
> 后端：无
> 数据库：无
> 目标平台：PC Web + 移动端 Web
> 核心体验时长：约 5～10 分钟

---

# 一、项目概述

## 1.1 项目名称

**《七月初七》**

副标题：

> 今夜有星河，亦有一笺寄你。

---

## 1.2 项目定位

这是一个以中国传统七夕文化中的：

- 女儿节
- 乞巧
- 织女
- 星河
- 星辰
- 祈愿

为核心意象制作的私人数字礼物网站。

网站并不采用现代“七夕 = 情人节”的常见表达方式，而是借用传统七夕“女儿节”和“乞巧”的文化意象，将网站设计成一次发生在七夕夜晚的短篇互动体验。

用户进入网站后，会经历：

1. 入夜
2. 女儿节
3. 星河
4. 乞巧
5. 七夕笺

最终打开一封专门写给她的信。

---
## 2.1 核心概念

  

网站不是：

  

> 七夕宣传页

  

不是：

  

> 情侣相册

  

不是：

  

> 年度总结

  

也不是：

  

> 传统文化介绍网站

  

而是：

  

> **一场发生在七夕夜里的私人数字礼物。**

  

用户应该感觉自己是在“夜晚中慢慢发现一些东西”，而不是不停点击网页。

  

---

  

## 2.2 情绪关键词

  

整体情绪：

  

- 安静

- 温柔

- 浪漫

- 克制

- 东方

- 夏夜

- 星河

- 私人

- 仪式感

- 微微神秘

  

避免：

  

- 俗套情侣风

- 大面积红色

- 心形元素泛滥

- 玫瑰

- 情人节宣传页风格

- 商业营销风格

- 过度古风

- 过度复杂的国潮视觉

- 大量文字堆叠

- API 层
- Repository
- Service
- 数据库
- 后端

# 四十一、最终产品体验目标

用户完成网站后，应该产生这样的感受：

> 原来今天是女儿节。

> 原来七夕还有这样的含义。

> 原来你记得这么多关于我的事情。

> 原来这些回忆都被藏在了星星里。

> 原来你还让我自己许了一个愿望。

> 最后还有一封信。

最终情绪不是：

> “这个网站功能好多。”

而应该是：

> **“你真的花时间为我做了这个东西。”**

---

# 四十二、项目完成定义

当以下条件全部满足时，项目视为 MVP 完成：

✓ 页面可以完整从头体验到尾

✓ 五个章节均可进入

✓ 星空正常显示

✓ 回忆星星可以点击

✓ 回忆内容来自 Mock 数据

✓ 回忆支持图片

✓ 图片可以放大查看

✓ 多图可以切换

✓ 乞巧可以选择

✓ 用户可以输入自己的愿望

✓ 愿望可以进入星河

✓ 七夕笺可以正常阅读

✓ PC 正常显示

✓ 移动端正常显示

✓ 无明显 JS 报错

✓ 无明显布局溢出

✓ 无核心交互阻塞

✓ 页面视觉统一

---

# 四十三、最终原则

这个项目只有一个最高优先级：

> **不要做一个“功能很多的七夕网站”。**

而是：

> **在 12 小时内，做一个足够精致、足够私人、足够安静的七夕数字礼物。**

内容可以少。

功能可以少。

图片可以少。

但：

**每一个出现的东西，都应该有意义。**
